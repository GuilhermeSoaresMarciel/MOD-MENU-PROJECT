## 📖 Sobre

O **MOD MENU PROJECT** é capaz de **carregar uma DLL que está no lado do servidor** e **utilizá-la para modificar aplicativos**. Como a DLL fica hospedada online, ela pode ser atualizada, corrigida ou trocada a qualquer momento, sem que o aplicativo precise ser recompilado ou reinstalado.

## ✨ Características

- ☁️ Carrega a DLL diretamente do servidor
- 🧩 Utiliza a DLL carregada para modificar aplicativos
- 🔄 Atualizações instantâneas, sem recompilar
- 🪶 Código extremamente pequeno e leve
- 🛠️ Compatível com Android Studio e AIDE
- 🤖 Gerenciado pelo hp-manager

## ⚙️ Como funciona

| Etapa | Descrição |
|:---:|---|
| 1️⃣ | O aplicativo inicia e se conecta ao servidor |
| 2️⃣ | A DLL hospedada no servidor é baixada e carregada |
| 3️⃣ | A DLL é utilizada para aplicar as modificações |
| 4️⃣ | Novas versões ficam disponíveis assim que o servidor é atualizado |

## ⚠️ Aviso

Este projeto existe **exclusivamente para fins educacionais**, para estudar o carregamento dinâmico de bibliotecas. Use apenas em aplicativos próprios ou naqueles em que você tenha autorização para testar, sempre em ambiente controlado. O autor não se responsabiliza pelo uso indevido.
